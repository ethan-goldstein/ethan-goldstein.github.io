Assignments

Assignment 1 - Basic HTML

This assignment introduced the basics of HTML by creating a webpage for Sweet Expressions. I used headings, paragraphs, images, lists, tables, and links to organize the content.

Assignment 2 - Basic CSS

This assignment improved my Sweet Expressions webpage by adding CSS. I used colors, spacing, image styling, backgrounds, and table styles to make the webpage more organized and appealing.

Assignment 3 - Page Layout

This assignment focused on page layout using Flexbox. I created a responsive webpage with navigation, columns, a sidebar, content sections, and a layout that changes for smaller screens.
